# 🌾 Agricultural Productivity, Profitability, Institutional Access, and Market Participation Analysis in Nigeria
## 📌 Project Overview

This project applies econometric and statistical techniques to analyze agricultural productivity, farm profitability, institutional access, and market participation among Nigerian farmers using Python.

The study integrates concepts from agricultural production economics, development economics, and applied econometrics to examine how production inputs, institutional support systems, and market conditions influence farm-level outcomes.

A structurally generated dataset containing 2,000 farm-level observations was developed to simulate realistic economic relationships among agricultural variables. Unlike purely randomized synthetic datasets, the dataset was engineered using structural equations to produce economically meaningful interactions between productivity, profitability, institutional access, and market participation variables.

This project is suitable for:
- Agricultural economics research
- Econometrics portfolios
- Data science portfolios
- Graduate school applications
- Development economics demonstrations
- Applied policy analysis projects

## Research Objectives
- Analyze the socioeconomic characteristics of farmers.
- Examine the determinants of agricultural productivity.
- Analyze the factors influencing farm profitability.
- Assess the effect of institutional access on productivity and profit.
- Examine market participation and marketed surplus among farmers.

## 🗂 Dataset Information
The dataset contains 2,000 farm-level observations and 31 variables covering:
- Farmer demographics
- Production characteristics
- Institutional access
- Market participation
- Production inputs
- Revenue and cost structures
- Profitability indicators

The dataset was structurally designed to reflect realistic agricultural production systems in Nigeria.

## ⚙️ Methodology
The project combines descriptive statistical analysis with econometric modeling techniques.
## 📈 Descriptive Analysis
The descriptive component includes:
- Summary statistics
- Frequency distributions
- Percentage analysis
- Correlation analysis

## 📉 Econometric Techniques
The study employs Ordinary Least Squares (OLS) regression to estimate:
- Determinants of agricultural productivity
- Determinants of farm profitability
- Institutional effects on productivity
- Determinants of marketed surplus

## 🧪 Diagnostic Tests
Several econometric diagnostic tests were conducted to validate model reliability:
- Variance Inflation Factor (VIF)
- Jarque–Bera Normality Test
- Breusch–Pagan Heteroskedasticity Test
- Correlation Matrix Analysis

## 🧠 Structural Dataset Design
Unlike purely randomized synthetic datasets, this dataset was generated using structural economic relationships to simulate realistic agricultural systems.
Examples of embedded structural relationships include:
- Fertilizer use positively affects yield
- Rainfall influences productivity
- Irrigation improves output
- Yield influences profitability
- Farm size affects marketed surplus
- Institutional access improves productivity
Additional behavioral and market variations were introduced to improve realism through:
- Household consumption variability
- Marketing inefficiencies
- Post-harvest loss variation
- Institutional heterogeneity
- Production shocks
